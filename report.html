A Cognitive Scaffolding System for Abstract Concept Simplification and Active Learning

摘要 (Abstract)

在高等教育與跨領域自學過程中，「術語黑話（Jargon）」常是阻礙理解的最大阻力，使初學者陷入「字都認得，合在一起卻完全看不懂」的困局。本專案 ConceptLens 是一套基於認知科學理論（認知負荷理論、雙重編碼理論與費曼學習法）開發的互動式概念解構系統。利用大語言模型（LLM）的語義轉化能力，將晦澀抽象的概念自動降維轉化為「5歲童生活比喻（ELI5）」、「大學通識運作機制」與「硬核數學本質」三層漸進透鏡，並開創「跨維度比喻轉換器（廚師、遊戲、偵探、運動）」、Mermaid 知識心智圖與主動提取（Active Recall）隨堂快問機制。本報告詳述本專案之產品架構、目標客群、人機協作方法論、學術文獻依據及未來拓展路徑。

一、做什麼 (What ConceptLens Does)

ConceptLens 的核心理念取自諾貝爾物理學獎得主理查·費曼（Richard Feynman）名言：「如果你不能用最簡單的話向外行人解釋清楚，代表你根本還沒有真正搞懂它。」 本專案旨在將生成式 AI 從單純的「問答機器人」，升級為具備認知階梯引導力（Cognitive Scaffolding）的教育透鏡，使抽象知識具象化、結構化、可玩化。

1.1 核心功能模組矩陣

  • 三層費曼認知透鏡 (3-Level Feynman Lens)：
    • Level 1 (5 歲白話比喻)：杜絕學術術語，映射至兒童生活常識（如以「測速照相機拍下的那一瞬間」比喻大學微積分的瞬時速度與極限；以「吵雜派對上的神奇聚光燈」比喻注意力機制）。
    • Level 2 (大學通識剖析)：拆解該技術解決了何種歷史痛點（如牛頓突破 0/0 未定式危機求出瞬時加速度；以 YouTube 搜尋 Q, K, V 映射注意力機制）。
    • Level 3 (硬核本質與數學公式)：KaTeX 即時渲染規範公式（如導數定義極限式 $f'(x) = \lim_{\Delta x \to 0} \frac{f(x+\Delta x)-f(x)}{\Delta x}$、微積分基本定理 $\int_a^b f(x)dx = F(b)-F(a)$），深入分析切線斜率、反導函數與邊界限制。
  • 跨維度生活比喻轉換器 (Analogy Switcher)：提供「🍳 頂級大廚配方」、「🎮 RPG 副本組隊」、「🕵️ 福爾摩斯辦案」與「🏀 NBA 球隊戰術」等不同生活語境轉換，破除單一視角思維盲區。
  • 動態因果心智圖 (Interactive Mindmap)：透過 Mermaid.js 動態繪製割線收斂為切線、黎曼和累積為定積分等因果拓撲流。
  • 直覺考驗小快問 (Active Recall Quiz Engine)：針對直覺易混淆盲點設計互動單選題，點選即時給予觀念回饋。
  • 離線知識庫與即時 LLM 雙模支援：內建 7 套高擬真預載資料庫（涵蓋大學微積分：微分瞬時時速、微積分基本定理、Transformer 注意力等），並支援選填 Gemini API Key 即時解構未知概念。

二、給誰用 (Target Audience & Use Cases)

大專跨領域修課者

非本科系學生修讀前沿科技或跨院系課程時，面對晦澀教材常陷入「外在認知超載」，本工具提供最快速的直覺鋪墊。

自學開發者與科技愛好者

面對 AI 論文（如 Attention Is All You Need）時，能在 5 分鐘內建立高保真具象架構，加速實務工程代碼研讀。

教學講師與知識創作者

需要將複雜概念以通俗語言向大眾分享的教育者，可從中獲取多元生動的生活隱喻與教材結構靈感。

三、怎麼跟 AI 一起做 (Human-AI Collaboration)

在本專案的開發週期中，AI 並非單純作為「代寫程式碼」的工具，而是被定位為「認知架構共創者（Cognitive Co-Architect）」。協同流程分為三大維度：

1. 提示工程與認知架構契約 (Cognitive Schema Contracting)

初期實驗顯示，若單純詢問「請用白話解釋 Transformer」，AI 往往給出冗長且缺乏張力的文字。為此我們共同制定了嚴格的 JSON Schema 約束，強制輸出包含具體實體道具情節（ELI5）、歷史痛點剖析、四大跨域比喻與 Mermaid 箭頭語法，達成精準結構化。

2. 零依賴單頁工程實作 (Zero-Dependency Single-Page Architecture)

考量課堂展示與 GitHub 開源分享便利性，我們採用 Tailwind CDN、Lucide Icons、KaTeX 與 Mermaid.js，打造出無須配置 Node.js 或複雜虛擬環境、雙擊即可完整運行的現代化 Web 原型。

3. 教學比喻校準與認知防呆 (Pedagogical Alignment & Anti-Hallucination)

例如在詮釋量子糾纏時，防範大眾常犯的「超光速傳送簡訊」迷思，我們將科學限制反向包裝為隨堂快問的診斷題，使錯誤直覺在答題時被立即矯正。

四、查了什麼 (Research & Theoretical Foundations)

本專案的設計全面奠基於四項認知科學經典理論：

認知負荷理論 (Sweller, 1988)

人類工作記憶容量極為有限。透過生活化比喻消除非必要的外在認知負荷（Extraneous Load），釋放心理能量建構心智基模（Germane Load）。

雙重編碼理論 (Paivio, 1971)

語言與非語言（視覺圖形）為大腦平行的獨立處理通道。將文字比喻與 Mermaid 因果圖併行展示，顯著深化長時記憶儲存。

費曼學習法 (Richard Feynman)

「不能向外行人講明白就是沒搞懂」。透過階梯式降維（5歲兒童 ➔ 通識原理 ➔ 硬核公式），檢證理解深度。

提取練習效應 (Roediger & Karpicke, 2006)

主動提取（Active Recall）遠比反覆劃重點更具記憶保持力。每項概念皆附帶隨堂反思測驗，有效抵禦遺忘曲線。

五、下一步 (Next Steps & Future Roadmap)

  • 短期目標：瀏覽器劃詞擴充套件 (Chrome Extension)：將 ConceptLens 封裝為瀏覽器外掛，在閱讀學術論文或長文時，反白單字即懸浮展現三層透鏡與心智圖。
  • 中期目標：多模態蘇格拉底語音對話教練：支援語音口述作答，由 AI 扮演蘇格拉底進行動態追問，檢視概念邏輯是否嚴密。
  • 長期願景：社群共創「人類生活比喻圖譜」：建立開放式知識庫，讓廣大自學者投稿自己發明的生活絕妙類比，並由社群票選最具啟發性的解釋視角。
